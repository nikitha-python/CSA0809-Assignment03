* CSA0809 - Python Programming

## About
This repository contains the code for Assignment 3. It covers Python lists, tuples, dictionaries, sets and comprehensions through seven small real-world problems. Each program is a separate Python file.

## Programs

| No. | Topic | File | Concepts |
|-----|-------|------|----------|
| 1 | Daily Rainfall Records | `Q1_Rainfall.py` | Lists, slicing, sum/max/min, moving average |
| 2 | Tuples, Mutability and Copying | `Q2_Tuples_Copying.py` | Tuples as dictionary keys, aliasing, shallow and manual deep copy |
| 3 | Farmer Helpline Complaint Analysis | `Q3_Complaints.py` | Dictionaries, word frequency |
| 4 | Elective Registration Clash Detection | `Q4_Electives.py` | Sets, union, intersection, difference |
| 5 | Cleaning Sensor Readings | `Q5_Sensor.py` | List and dictionary comprehensions |
| 6 | Railway Timetable | `Q6_Railway.py` | Nested dictionaries, searching, sorting by departure time |
| 7 | Contact Merging Program | `Q7_Contact_Merging.py` | Dictionaries and sets, merging duplicates by phone number |

## How to Run
Python 3 is required. No external libraries are needed.

```
python Q1_Rainfall.py
```

Replace the file name to run any other program.
